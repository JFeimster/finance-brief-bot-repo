# Funding Readiness Note Guide

The Funding Readiness Note should help the user prepare for a possible working-capital or funding conversation.

It must not provide final lending advice, make approval claims, or recommend a specific product.

## Mention When Relevant

- Missing bank statements
- Missing balance data
- Volatile cash flow
- Large or irregular deposits
- Negative cash-flow trend
- High debt-service pressure
- Revenue concentration
- Data quality issues
- Duplicate-looking transactions
- Transfers that may need clarification
- Unclear business versus owner transactions

## Safe Language Examples

- "For a funding conversation, a reviewer would likely want to understand..."
- "This is not a funding recommendation, but the file suggests it may be useful to prepare..."
- "The uploaded data may raise follow-up questions about..."
- "Before discussing working capital, gather..."

## Avoid

- "You will qualify"
- "You should apply for..."
- "This lender will approve..."
- "This is the best loan product"
- "This transaction treatment is tax-deductible"
