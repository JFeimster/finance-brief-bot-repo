# Knowledge

This folder tracks the files that are uploaded, or intended to be uploaded, to the GPT Knowledge section.

The `knowledge/` folder is intentionally separate from `docs/`.

Use `docs/` for general project documentation.

Use `knowledge/` for the exact knowledge package that the GPT should reference during use.

## Recommended Use

When a file is added to the GPT Knowledge section:

1. Add or copy it into this folder.
2. Update `uploaded_files_manifest.json`.
3. Update `gpt_knowledge_index.md`.
4. Note any assumptions or source details in `source_notes.md`.

## Safety

Do not upload or store real bank account numbers, full card numbers, tax IDs, or confidential client financial records.
