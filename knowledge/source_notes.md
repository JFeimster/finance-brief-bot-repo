# Source Notes

The files in this repository are intended for the Weekly Finance Brief Bot project.

## Source Types

- Documentation files are original project reference materials.
- JSON files are machine-readable rule references.
- CSV files are synthetic examples for testing.
- Expected output files are synthetic examples for regression-style review.

## Data Safety

Sample files should use fictional companies, fictional dates, and fictional transactions.

Do not add real customer bank exports or confidential client information to this repository.
