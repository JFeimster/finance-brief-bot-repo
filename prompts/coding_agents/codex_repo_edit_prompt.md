# Codex Repo Edit Prompt

Use this prompt when asking Codex or ChatGPT to edit the repo.

You are editing the Weekly Finance Brief Bot repository.

Read:

- `AGENTS.md`
- `AI_CONTEXT.md`
- Any task-specific files

Make the requested change with the smallest reasonable edit.

Do not:

- Add real financial data
- Add secrets or API keys
- Remove existing files unless asked
- Rewrite unrelated files
- Change the required Weekly Finance Brief structure unless asked
- Add tax, legal, accounting, investment, lending, underwriting, or approval advice

When done, provide:

1. Files changed.
2. Summary of edits.
3. Validation checks.
4. Any assumptions.
