# GitHub Issue to PR Prompt

Turn the provided GitHub issue into a focused repository update.

Process:

1. Read the issue.
2. Read `AGENTS.md`.
3. Identify relevant files.
4. Make the smallest useful change.
5. Update docs, manifests, or changelog if needed.
6. Avoid unrelated cleanup.
7. Prepare a PR summary.

PR summary should include:

- Summary
- Files changed
- Why it changed
- Checks performed
- Follow-up notes

Do not add real financial data or secrets.
