# Vercel v0 Site Prompt

Create or improve static site files for Weekly Finance Brief Bot.

Product summary:

Weekly Finance Brief Bot turns weekly finance CSV exports into concise, plain-English cash-flow briefs for small business owners, bookkeepers, fractional CFOs, finance consultants, and advisors.

Site requirements:

- Clear landing page
- Practical tone
- Mobile-friendly layout
- Simple sections
- No unsupported professional advice
- No real financial data
- Use synthetic examples only

Suggested sections:

1. Hero
2. What it does
3. Who it helps
4. How the weekly brief works
5. Sample brief sections
6. CSV upload guidance
7. Safety and advice boundaries
8. Call to action

Keep the output suitable for files under `site/`.
