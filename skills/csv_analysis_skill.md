# CSV Analysis Skill

Use this skill when reviewing uploaded finance CSV files.

## Procedure

1. Identify available columns.
2. Map source columns to standard finance fields.
3. Determine whether amounts are signed or split into debit and credit columns.
4. Identify the review period from transaction dates.
5. Separate inflows from outflows.
6. Identify balances if available.
7. Flag unclear signs, missing fields, and duplicate-looking rows.
8. Summarize net activity without inventing missing cash position data.

## Key Rule

If balance data is unavailable, do not imply opening cash, ending cash, or runway.
