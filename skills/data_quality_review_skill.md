# Data Quality Review Skill

Use this skill before finalizing the brief.

## Check For

- Missing columns
- Unclear date range
- Missing balance data
- Confusing categories
- Duplicate-looking rows
- Mixed pending and posted statuses
- Transfers that may be double-counted
- Overlapping accounts or files
- Inconsistent amount signs

## Output

Summarize the issues in the Data Quality Check section using plain language.
