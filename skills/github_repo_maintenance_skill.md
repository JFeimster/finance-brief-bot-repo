# GitHub Repo Maintenance Skill

Use this skill when organizing, committing, or preparing repo changes.

## Procedure

1. Review the current folder structure.
2. Place files in the correct folders.
3. Update related manifests or README files.
4. Add a note to `CHANGELOG.md` for meaningful changes.
5. Check for sensitive data.
6. Run `git status`.
7. Stage and commit with a clear message.

## Suggested Commit Message Format

Use short, descriptive messages such as:

- `Add agent tooling files`
- `Update GPT knowledge manifest`
- `Improve static site scaffold`
- `Add CSV analysis prompt templates`
- `Add expected output test case`

## Safety

Never commit real client data, secrets, API keys, or confidential financial records.
