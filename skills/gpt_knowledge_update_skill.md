# GPT Knowledge Update Skill

Use this skill when updating files intended for the GPT Knowledge section.

## Procedure

1. Decide whether the file belongs in `knowledge/`, `docs/`, `config/`, or another folder.
2. If the file will be uploaded to GPT Knowledge, record it in `knowledge/uploaded_files_manifest.json`.
3. Update `knowledge/gpt_knowledge_index.md` with a short explanation of how the GPT should use the file.
4. Add source or version notes to `knowledge/source_notes.md` if relevant.
5. Avoid duplicate or conflicting instructions.
6. Keep safety and advice boundaries clear.

## Review Checklist

- File purpose is clear.
- GPT-facing guidance is concise.
- No real financial data is included.
- No unsupported advice is added.
- Manifest and index are up to date.
