# Prompt Library Maintenance Skill

Use this skill when adding or updating files in `prompts/`.

## Procedure

1. Identify the intended user or tool for the prompt.
2. Place the prompt in the correct subfolder.
3. Use a clear filename.
4. Make the prompt reusable.
5. Include guardrails against invented numbers and unsupported advice.
6. Update `prompts/json/prompt_manifest.json` when adding a new prompt.
7. Check that the prompt does not conflict with the GPT’s standard behavior.

## Prompt Quality Checklist

- Clear task
- Clear input expectation
- Clear output format
- Practical tone
- Safety boundaries
- No unnecessary complexity
