# Static Site Update Skill

Use this skill when updating files in the `site/` folder.

## Procedure

1. Identify which page, widget, or asset needs to change.
2. Keep the site static HTML/CSS/JS unless a framework is requested.
3. Preserve existing internal links.
4. Use clear, practical, founder-friendly copy.
5. Avoid tax, legal, accounting, investment, lending, or approval claims.
6. Use synthetic example data only.
7. Check that the page title, heading, and navigation make sense.
8. Update `tooling/vercel/vercel_deploy_checklist.md` if deployment assumptions change.

## Output

Summarize changed site files and any manual review steps.
