# Weekly Brief Generation Skill

Use this skill after CSV analysis is complete.

## Procedure

1. Create the standard Weekly Finance Brief.
2. Include the review period and prepared-for line.
3. Summarize cash position or net activity.
4. Summarize money in.
5. Summarize money out.
6. Add 3 to 5 watch items.
7. Add 1 to 3 recommended next actions.
8. Add a Funding Readiness Note.
9. Add a Data Quality Check.

## Style

Keep the output practical, calm, direct, and readable in under three minutes.
