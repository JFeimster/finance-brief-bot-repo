# Tooling

This folder contains tool-specific instructions for AI coding assistants and deployment tools.

## Included Tooling Areas

- `codex/` — Instructions for Codex or ChatGPT coding workflows.
- `jules/` — Instructions for Google Jules-style GitHub task workflows.
- `vercel/` — Static site, Vercel, and v0 notes.
- `github/` — GitHub issue and pull request templates.
- `cursor/` — Cursor-oriented repo editing rules.
- `replit/` — Replit Agent or app-builder notes.

## General Guidance

Tool-specific instructions should support the repo’s structure without duplicating all project documentation.

Use `AGENTS.md` for repo-wide agent behavior.

Use this folder for tool-specific workflows, prompts, and checklists.
