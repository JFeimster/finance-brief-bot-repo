# Codex Instructions

Use this file when asking Codex or ChatGPT coding tools to edit the repository.

## Project Summary

This repo supports Weekly Finance Brief Bot, a custom GPT that analyzes finance CSVs and produces plain-English weekly cash-flow briefs.

## Editing Preferences

- Keep edits focused and easy to review.
- Preserve the required brief output format.
- Do not remove existing docs, samples, config files, or tests unless asked.
- Update related manifests when adding new files.
- Use synthetic data only.
- Keep JSON valid.
- Keep Markdown readable.
- Keep the static site simple unless asked to add a framework.

## Good Codex Tasks

- Add a new sample CSV.
- Add an expected output file.
- Improve static HTML/CSS.
- Add prompt templates.
- Add documentation for a new CSV source.
- Expand API schema placeholders.
- Add validation notes.

## Avoid

- Adding real financial data.
- Adding credentials or secrets.
- Making product, funding, approval, tax, legal, accounting, or investment claims.
- Rewriting the whole repo when a small edit is requested.
