# Cursor Rules

## Project Context

This repo supports Weekly Finance Brief Bot, a custom GPT for turning weekly finance CSV exports into cash-flow briefs.

## Editing Rules

- Read `AGENTS.md` before making broad changes.
- Keep edits focused.
- Do not rewrite unrelated files.
- Preserve the standard Weekly Finance Brief format.
- Keep Markdown readable.
- Keep JSON valid.
- Use synthetic sample data only.
- Do not add secrets, API keys, real bank data, account numbers, card numbers, tax IDs, or confidential customer information.

## Site Rules

The `site/` folder is currently static HTML/CSS/JS.

Do not add a framework unless requested.

## Prompt Rules

Prompts should be practical, reusable, and clearly scoped.

Avoid prompts that encourage tax, legal, accounting, investment, lending, or underwriting advice.
