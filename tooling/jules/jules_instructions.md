# Jules Instructions

Use this file when assigning GitHub-based tasks to Jules.

## Planning

Before editing, Jules should:

1. Read `AGENTS.md`.
2. Review `AI_CONTEXT.md`.
3. Identify the files likely to change.
4. Make a small, focused plan.
5. Avoid unrelated edits.

## Safe Editing Areas

Jules can generally edit:

- `docs/`
- `config/`
- `knowledge/`
- `actions/`
- `skills/`
- `site/`
- `prompts/`
- `tooling/`

Jules should be careful when editing:

- `tests/`
- `samples/`
- `repo_manifest.json`
- `agents.json`

## Pull Request Summary

When opening or preparing a PR, include:

1. Summary of changes.
2. Files changed.
3. Why the change was made.
4. Checks performed.
5. Any follow-up tasks.

## Safety

Do not add real financial data, secrets, API keys, account numbers, tax IDs, or confidential customer information.
