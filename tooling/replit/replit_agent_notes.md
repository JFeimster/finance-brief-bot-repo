# Replit Agent Notes

## Project Goal

Replit Agent may be used later to turn the static `site/` folder into a more interactive tool.

## Possible Future App Features

- CSV readiness checker
- Sample brief viewer
- Watch item explainer
- Funding readiness preparation checklist
- Prompt library browser
- Knowledge file index viewer

## Development Rules

- Use synthetic data only.
- Do not store real uploaded financial files.
- Do not add authentication or database features unless requested.
- Do not add API keys or secrets to the repo.
- Keep any generated app simple and easy to deploy.
- Preserve the existing documentation and prompt files.

## Safety

The app should not provide final tax, legal, accounting, investment, lending, underwriting, or funding approval advice.
