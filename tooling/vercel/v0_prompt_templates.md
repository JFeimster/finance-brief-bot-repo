# v0 Prompt Templates

Use these prompts with v0 or another frontend generation tool.

## Landing Page Prompt

Create a clean, professional static landing page for Weekly Finance Brief Bot. The product turns weekly finance CSV exports into concise, plain-English cash-flow briefs for small business owners, bookkeepers, fractional CFOs, and advisors. Include sections for what it does, who it helps, sample output sections, CSV upload guidance, and safety disclaimers. Keep the tone calm, practical, and trustworthy. Do not make tax, legal, accounting, lending, or approval claims.

## Examples Page Prompt

Create an examples page for Weekly Finance Brief Bot showing a sample Weekly Finance Brief layout. Include Cash Position Snapshot, Money In, Money Out, Watch Items, Recommended Next Actions, Funding Readiness Note, and Data Quality Check. Use fictional data only.

## CSV Readiness Widget Prompt

Create a simple static HTML/CSS/JS widget that helps users check whether their CSV is ready for analysis. Include checkboxes for Date, Description, Amount or Debit/Credit, Balance, Category, Account, and Status. Show a simple readiness message based on checked fields.

## GPT Embed Page Prompt

Create a clean page that explains how to use or embed the Weekly Finance Brief Bot. Include placeholder text for a future GPT link or embed. Keep the page simple and mobile-friendly.
