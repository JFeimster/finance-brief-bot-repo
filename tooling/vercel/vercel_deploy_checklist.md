# Vercel Deploy Checklist

Before deploying:

1. Confirm `site/index.html` opens locally.
2. Confirm stylesheet path works.
3. Confirm JavaScript path works.
4. Confirm internal links work.
5. Confirm no real financial data appears.
6. Confirm site copy does not make tax, legal, accounting, investment, lending, or approval claims.
7. Confirm sample data is synthetic.
8. Confirm mobile viewport is included.
9. Confirm page titles and meta descriptions are reasonable.

## Suggested Vercel Setup

- Framework preset: Other
- Root directory: `site`
- Build command: none
- Output directory: none or default static directory, depending on Vercel setup

If the project is later converted to Next.js or another framework, update this file.
