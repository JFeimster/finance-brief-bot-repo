# Vercel Project Notes

## Current Site Type

The site is currently a static HTML/CSS/JavaScript project located in `site/`.

## Deployment Goal

The site should explain the Weekly Finance Brief Bot, show examples, provide upload guidance, and eventually host simple widgets or tools.

## Recommended Pages

- Home
- About
- Examples
- Upload Guide
- FAQ
- Changelog
- GPT Embed Page

## Recommended Widgets

- CSV readiness checklist
- Sample cash-flow summary
- Watch item examples
- Funding readiness preparation checklist

## Design Guidance

Keep the design:

- Clear
- Practical
- Trustworthy
- Founder-friendly
- Easy to read
- Mobile-friendly

Avoid making funding, lending, tax, accounting, or legal claims.
